# 경기도 노인인구 현황

경기도 31개 시군의 65세 이상 인구를 성별·연령별·소득(기초연금 수급 여부)별로 보여 주고, 평택시 원평동·세교동·비전1동·비전2동·동삭동·용이동·신평동을 따로 정리한 웹페이지입니다.

## 자료
- 인구: 행정안전부 주민등록 인구통계 「연령별 인구현황」(매월 공개) — https://jumin.mois.go.kr/ageStatMonth.do
- 소득 구분: 보건복지부 「기초연금 인구·수급률 현황」(공공데이터포털 15161618) — https://www.data.go.kr/data/15161618/fileData.do
  기초연금은 소득 하위 약 70%에게 지급되므로 수급/비수급을 소득 구분의 근사치로 사용합니다.

## 갱신
매월 1일 `python update.py`를 실행하면 최신 자료를 받아 `data.json`, `index.html`(웹 호스팅용), `artifact.html`을 다시 만듭니다.

## 파일
- `update.py` 데이터 수집·페이지 생성
- `template.html` 페이지 디자인(데이터 자리 `/*__DATA__*/null`)
- `data.json` 정리된 데이터
- `raw/pension.csv` 기초연금 원자료(다운로드 실패 시 대체용)
